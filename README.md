# SUNGSOO × MINJUNG 모바일 청첩장

한성수 · 손민정 결혼식 모바일 청첩장입니다. 2027년 1월 24일(일) 오전 11시, 소노펠리체컨벤션.
코딩을 몰라도 `data.js` 파일의 글자만 바꾸면 내용이 바뀌도록 만들었어요.

## 1. 파일 구조

```
minjeong-seongsu-wedding/
├─ index.html        화면의 뼈대 (건드리지 않아도 됩니다)
├─ style.css         색·글꼴·간격 (색을 바꾸고 싶을 때만)
├─ script.js         버튼·팝업·갤러리 등 동작 (건드리지 않아도 됩니다)
├─ data.js           ★ 날짜·문구·사진 목록·가족·계좌·RSVP 주소가 모여 있는 파일
├─ images/           ★ 사진 폴더 (지금은 임시 사진이 들어 있어요)
├─ apps-script/
│  └─ Code.gs        참석 여부를 구글 시트에 저장하는 코드 (GitHub 가 아니라 구글에 붙여넣기)
├─ README.md         이 설명서
└─ .gitignore        GitHub 에 올리지 않을 파일 목록
```

## 2. GitHub 로 공개하기 (무료, 약 15분)

컴퓨터에 아무것도 설치하지 않고 웹사이트에서 끝낼 수 있어요.

1. https://github.com 에서 **회원가입 / 로그인**합니다.
2. 오른쪽 위 **+ → New repository** 를 누릅니다.
3. **Repository name** 에 `minjeong-seongsu-wedding` 을 입력하고, **Public** 을 선택한 뒤 **Create repository** 를 누릅니다.
   (무료 계정은 GitHub Pages 를 Public 저장소에서만 쓸 수 있어요.)
4. 만들어진 화면에서 **uploading an existing file** 링크를 누릅니다.
5. 압축을 푼 폴더 **안의 내용물**(index.html, style.css, script.js, data.js, README.md, .gitignore, `images` 폴더, `apps-script` 폴더)을 모두 끌어다 놓습니다.
   - 폴더째 올릴 때는 `minjeong-seongsu-wedding` 폴더 자체가 아니라 **그 안의 파일들**을 선택해야 해요. 그래야 `index.html` 이 저장소 맨 위에 놓입니다.
   - 숨김 파일(.gitignore)이 안 보이면 건너뛰어도 괜찮아요.
6. 아래 **Commit changes** 를 누릅니다.
7. 위쪽 **Settings → 왼쪽 Pages** 로 들어갑니다.
8. **Build and deployment → Source** 를 `Deploy from a branch` 로, **Branch** 를 `main` / `/ (root)` 로 고르고 **Save** 를 누릅니다.
9. 1~2분 기다린 뒤 Pages 화면을 새로고침하면 주소가 나타납니다.

   `https://내GitHub아이디.github.io/minjeong-seongsu-wedding/`

   이 주소를 카카오톡으로 보내면 됩니다. 도메인 비용은 없습니다.
10. **꼭 확인**: 휴대폰(와이파이를 끈 상태)에서 주소를 열어 인트로, 사진, 메뉴, 지도 버튼이 모두 되는지 보세요.

> 나중에 수정할 때: GitHub 저장소에서 파일(예: `data.js`)을 열고 연필 아이콘(✏️)으로 고친 뒤 **Commit changes**. 1~2분 뒤 반영됩니다. 폰에서 예전 내용이 보이면 주소 끝에 `?v=2` 를 붙여 열어보세요.

## 3. 사진 바꾸기

1. 사진 용량을 줄입니다. 가로 1600px 안팎, 장당 **300KB 이하**를 권장해요. (예: squoosh.app 에서 무료로 압축)
2. 파일 이름은 영어 소문자·숫자·하이픈만 씁니다. 예: `photo-01.jpg`
3. `images` 폴더의 임시 사진과 **같은 이름으로 덮어쓰면** 끝입니다. (photo-01 ~ photo-08)
4. 사진 수를 바꾸고 싶으면 `data.js` 의 `photos` 부분을 고칩니다.
   - `intro` 맨 처음 화면의 **대표(모션) 사진** 1장. 천천히 움직이는 효과가 들어가고 그 위에 "성수 ♥ 민정 결혼합니다"와 날짜·예식장 정보가 올라가요.
   - `heroVideo` (선택) 짧은 영상을 쓰고 싶을 때 파일 경로 (예: `'images/hero.mp4'`). 아래 "모션 포토" 참고
   - `heroFocus` 사진이 잘릴 때 중심으로 삼을 위치 (예: `'50% 30%'` = 위쪽 중심)
   - `featured` 메인에 보이는 3장 (첫 번째가 크게)
   - `gallery` 사진 더 보기에서 보는 전체 사진 (몇 장이든 OK, `03 / 18` 처럼 숫자가 자동으로 바뀝니다)
   - `closing` 마지막 화면 사진
5. **모션 포토**: 기본은 사진이 아주 천천히 확대·이동하는 효과예요. 진짜 영상처럼 움직이게 하려면 폰으로 찍은 짧은 영상(3~5초, 소리 없이, 3MB 이하 권장)을 `images/hero.mp4` 로 올리고 `heroVideo: 'images/hero.mp4'` 로 적으세요. 영상이 재생되지 않는 폰에서는 자동으로 사진이 보입니다. (`동작 줄이기`를 켠 폰에서는 움직임 없이 사진만 보여요.)
6. 메인의 대표 사진 3장은 칸 모양에 맞춰 살짝 잘려 보일 수 있어요. **전체 갤러리에서는 원본 비율 그대로** 보입니다.

## 4. 문구·정보 바꾸기 (모두 `data.js`)

| 바꾸고 싶은 것 | `data.js` 에서 찾을 곳 |
|---|---|
| 예식 날짜·시간 | `weddingDateTime` (끝의 `+09:00` 은 지우지 마세요). D-Day·요일·시간 표기가 모두 자동 변경 |
| 예식장 이름·층·주소 | `venue` |
| 초대의 말·감사 인사 | `texts` (줄바꿈은 `\n`) |
| 부모님 성함 | `families` 의 `father`, `mother` (비워두면 "준비 중") |
| 계좌 | `accounts` (은행·예금주·번호를 **모두** 써야 표시됨). 여러 개는 `{ ... },` 덩어리를 복사해 붙이기 |
| 교통 안내(지하철·버스·주차) | `transport` |
| **하객 안내** (유모차·휠체어, 식사·연회장, ATM) | `guide` — 「준비 중입니다.」 로 되어 있는 곳을 예식장에 확인한 뒤 바꿔 적으세요 |
| 오시는 길 지도 사진 | `venue.mapImage` (images/map.jpg 를 새 캡처로 덮어써도 됩니다) |
| 예식장 좌표 | `venue.lat`, `venue.lng` (아래 5번) |
| 지도 링크 | `mapLinks` |

⚠ **계좌번호 주의**: 저장소가 Public 이라 `data.js` 에 넣은 계좌번호는 소스 코드를 보는 누구나 볼 수 있어요. 공유해도 괜찮은 계좌만 넣으세요.

## 5. 지도 · 네비게이션 연결

오시는 길에는 네이버 지도 화면(사진)과 **네이버지도 / 티맵 / 카카오내비** 버튼이 있어요.

| 버튼 | 휴대폰에서 | 컴퓨터에서 |
|---|---|---|
| 네이버지도 (지도 사진·"지도 보기" 포함) | 네이버지도 앱이 열리고 "소노펠리체컨벤션" 검색 결과가 나와요 | 주소를 복사해 드려요 |
| 티맵 | 티맵 앱이 열리고 "소노펠리체컨벤션" 검색 결과가 나와요 | 주소를 복사해 드려요 |
| 카카오내비 | 카카오맵의 예식장 화면이 열려요 (거기서 길찾기·내비 연결) | 카카오맵 웹 지도가 열려요 |

- 안드로이드는 앱이 없으면 설치 화면으로 이동하고, 앱이 열리지 않을 때는 **주소를 복사하고 안내 문구**를 띄워요. (아이폰도 동일)
- **카카오내비**는 카카오가 "외부에서 앱을 직접 여는 방법(URL 스킴)을 지원하지 않는다"고 공식 안내했어요. 그래서 카카오맵을 엽니다. 카카오내비 앱을 바로 띄우려면 카카오 개발자 사이트의 JavaScript 키와 예식장 좌표가 필요해요. 필요하면 말씀해 주세요.
- **도착지로 바로 길찾기**를 원하면 `data.js` 의 `venue.lat`, `venue.lng` 에 예식장 좌표를 넣으세요. (네이버 지도에서 예식장을 길게 눌러 나오는 좌표, 또는 지도 앱 공유 정보에서 확인) 좌표를 넣으면 네이버·티맵은 "도착지 길찾기" 화면으로, 카카오는 "도착지 길찾기" 링크로 바뀝니다. 확인되지 않은 값을 임의로 넣지 않도록 지금은 비워두었어요.
- 앱별 공유 링크를 `mapLinks` 에 넣으면 그 링크가 **최우선**으로 열립니다.
- 앱 실행 방식은 네이버(공식 문서 기준)와 티맵(공개된 사용 사례 기준)입니다. 티맵 앱 업데이트로 동작이 달라질 수 있으니, 배포 후 **본인 폰으로 꼭 눌러보세요.**

## 6. 참석 여부(RSVP) 저장 연결 — 무료

GitHub Pages 는 정적 페이지라 응답을 직접 저장할 수 없어요. **구글 스프레드시트 + Apps Script** 를 쓰면 무료이고 비밀번호도 필요 없습니다. 응답은 내 구글 드라이브 시트에만 쌓여요.

**연결 전에는** 참석 폼에 "저장 기능이 연결되지 않았다"는 안내가 뜨고, 제출해도 저장된 것처럼 보이지 않습니다.

1. https://sheets.google.com 에서 **빈 스프레드시트**를 만들고 이름을 `청첩장 응답` 으로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 모두 지우고, 이 폴더의 `apps-script/Code.gs` 내용을 **전부 복사해 붙여넣기** → 저장(💾).
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. **배포** → 권한 승인 창이 뜨면 내 구글 계정으로 허용합니다. ("확인되지 않은 앱" 경고가 나오면 **고급 → 안전하지 않은 페이지로 이동**. 내가 만든 코드라서 괜찮아요.)
6. 나온 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.
7. `data.js` 의 `rsvp` 부분에 붙여넣습니다.

   ```js
   rsvp: {
     endpoint: 'https://script.google.com/macros/s/여기에복사한주소/exec',
   ```
8. GitHub 에 `data.js` 를 올린 뒤, 공개 주소에서 직접 한 번 제출해 보세요. 시트에 `응답` 탭이 생기고 줄이 쌓이면 성공입니다. (테스트 응답은 시트에서 지우면 돼요.)

**알아둘 점**
- 웹 앱 URL 은 공개 코드에 들어가지만, 이 주소로는 **응답을 추가만 할 수 있고 읽을 수는 없어요.** 읽으려면 내 구글 계정으로 시트를 열어야 합니다. 그래서 비밀 키가 필요 없습니다.
- `Code.gs` 를 고쳤다면 **배포 → 배포 관리 → 새 버전**으로 다시 배포해야 반영돼요. (주소는 그대로)
- 같은 폰에서 다시 제출하면 새 줄이 아니라 **기존 줄이 수정**됩니다.
- 하루 수천 건까지는 무료 한도 안에서 충분합니다.

**방명록**을 추가하고 싶다면 같은 방식(시트에 저장)으로 확장할 수 있어요. 다만 다른 하객에게 글을 보여주려면 공개 읽기와 악성 글 관리가 필요해서, 이번 초안에는 넣지 않았습니다.

## 7. 카카오톡 미리보기(사진·제목)

1. 미리보기에 쓸 사진을 `images/og.jpg` 로 올립니다. (가로 1200 × 세로 630 권장, 300KB 이하)
2. `index.html` 안의 주석(`<!-- ... -->`)으로 막아둔 `og:image` 줄에서 앞뒤 주석 표시를 지우고, `내GitHub아이디` 를 실제 아이디로 바꿉니다.
3. 카카오톡은 한 번 만든 미리보기를 기억해서, 바꾼 뒤에는 https://developers.kakao.com/tool/clear/og 에서 캐시를 지워야 반영될 수 있어요.

## 8. 기타

- **인트로 다시 보기**: 주소 끝에 `?intro=1` 을 붙여 여세요. (처음 방문에만 나오고, 이후 방문에서는 자동 생략됩니다.)
- **검색 노출 차단**: 계좌·일정이 있어 `noindex` 를 켜뒀어요. 주소를 아는 사람 중심으로 공유됩니다. (완전한 비공개는 아니에요.)
- **참석 안내 팝업**: 메인 진입 약 3초 후 한 번 나타나고, 응답을 보낸 브라우저에서는 다시 안 나옵니다. 시간은 `rsvp.autoPopupDelayMs` 로 조절합니다.
- **미리보기만 로컬에서 보기**: 폴더 안의 `index.html` 을 더블클릭해도 대부분 보이지만, 복사 기능 등은 GitHub 주소에서 확인하는 게 정확합니다.
- **영구 보관**: 이 폴더 전체를 따로 백업해 두세요. 호스팅이 바뀌어도 어디든 다시 올릴 수 있어요.
